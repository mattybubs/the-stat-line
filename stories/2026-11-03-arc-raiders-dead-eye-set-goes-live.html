ARC Raiders' Dead Eye Set Goes Live

By Matt

Store update 2.4.0 is live in ARC Raiders with the new Dead Eye Set — and no restart is required to pick it up.

Disclosure: this post contains affiliate links. I earn a commission on qualifying purchases.

ARC Raiders' store update 2.4.0 is going live, and it brings the new Dead Eye Set to the in-game store. Best part for players already logged in: no restart is required to pick it up.

The Dead Eye Set

The headline of store update 2.4.0 is the Dead Eye Set, now available in the ARC Raiders store. The update is rolling out live, so the set should be waiting in the store the next time you check — no download-and-restart dance first.

A fix for the Raider Tool

Update 2.4.0 also fixes a visual issue with the Raider Tool: it had been appearing in its default look even when other skins were equipped. With this update, the tool should show the skin you actually have equipped.

Back to the regular schedule

Alongside the set and the fix, the update marks a return to the regular store cadence: weekly store updates, with fixes every three weeks.
